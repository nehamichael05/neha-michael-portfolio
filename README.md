# Neha Michael | Portfolio

My personal portfolio, built with React, Vite and Tailwind CSS. It has no backend and no database.

## Sections

- About, with my details and key numbers
- Skills, grouped by area
- Projects, with a short description of each
- Experience and research
- Contact

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
